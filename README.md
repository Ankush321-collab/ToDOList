# 📝 Task Management Web Application - ToDoList

A simple and powerful web-based ToDo List application for managing daily tasks efficiently.

## 🚀 Features

- ✅ Add, edit, delete tasks
- 📅 Set due dates and priorities
- 📊 Track completed vs pending tasks
- 🔐 User authentication (login/register)
- 📂 Clean UI with Bootstrap
- 🗃️ SQLite database

## 🛠️ Tech Stack

- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, Bootstrap
- **Database**: SQLite
- **Other**: Jinja2 templating, SQLAlchemy, Flask Extensions
